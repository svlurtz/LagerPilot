# LagerPilot
## Auf dem iPhone oder iPad öffnen  1. Die GitHub-Pages-Adresse in Safari öffnen. In Safari **Teilen → Zum Home-Bildschirm** wählen. Falls der Dialog „Als Web-App öffnen“ anbietet, die Option eingeschaltet lassen. 2. Über das neue Symbol starten und online warten, bis **Offline bereit** angezeigt wird. Danach kannst du im Flugmodus neu öffnen.
